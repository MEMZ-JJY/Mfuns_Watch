## Mfuns API 要点（来自 ymltsh/Mfuns_Flutter 源码，master 分支）
- 主机 `https://api.mfuns.net`，路径 `/v1/`；`Authorization` 头**裸 token 无 Bearer**；响应 `{code,msg,data}`，`code==1` 成功。
- 登录 `POST /v1/auth/login`（form：account/password）→ access_token；会话校验 `GET /v1/user/info`。
- 资源类型：0 文章 / 1 视频 / 3 动态 / 4 评论。封面头像 `/static/...` 或 `//` 开头要补全为 `https://cdn2.mfuns.net`。
- 已用端点：recommend/get、leaderboards/hot、feeds/new_reply_list、search/resource、search/user、category/all、article/get、video/get、video/getPlayAddress、comment/list、comment/create、like/status|like|cancel、reward/reward、favorite/*、history/get、sign/sign|sign_list、message/list|record|send、notify/count|get、follow/*、user/get_user、article/user_list、video/user_list。
- open.mfuns.net 是投稿开放平台（上传凭证/文章投稿），与读取型社区 API 是两套；手表端只读为主，用社区 token 模式。

## 踩坑记录（Kotlin/Compose/Wear，均实证）
1. wear-compose-foundation 1.4.0 aar 里**没有** pager 包 → 用 `androidx.compose.foundation.pager.HorizontalPager + rememberPagerState`，页码指示器自绘小圆点。
2. wear material 1.4.0 **没有** IconButton、Divider → 用 Chip / Box 画线。
3. wear navigation 不传递 navigation-compose → 必须显式 `implementation(libs.navigation.compose)` 否则 `composable{}` 不可见。
4. wear `Chip(onClick, colors, border, ...)` 重载 colors/border 必传；优先用 `Chip(label, onClick, secondaryLabel, icon, colors)` 重载（有默认值）。方法名是 `ChipDefaults.secondaryChipColors()` 不是 secondaryChips()。
5. `@Volatile var token` 与 `fun setToken()` JVM 签名冲突 → 私有字段 authToken。
6. `by flow.collectAsStateWithLifecycle()` 委托属性不能 smart cast → `when (val s = state)` 局部变量。
7. ScalingLazyColumn/items 在 wear 1.4 有 deprecation 警告（迁到 foundation.lazy 包），功能正常暂不动。
8. suspend 函数（SessionStore.current）必须在协程内调用。
9. MediaType.parse 废弃 → `import okhttp3.MediaType.Companion.toMediaType`。
10. 注释剥离用状态机脚本（`.tools/strip_comments.py`，区分字符串/字符字面量），23 个文件一次过，构建复验通过。
